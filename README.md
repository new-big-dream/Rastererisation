# Rastererisation
Le but de ce programme et de convertir un fichier .obj (qui représente un objet 3D) en un rendu 2D convaincant. L'intérêt de ce code réside moins dans son utilisation pratique que dans l'exploration de ses fonctions et de leur structure ; il est fortement commenté en français afin d'en faciliter la lecture.


Voici quelques exemples de rendus générés très rapidement, sans texture. Les deux premiers rendus utilisent l'ombrage de Phong, le dernier n'utilise qu'une coloration selon la profondeur du triangle (avec suppression des faces cachées) :
